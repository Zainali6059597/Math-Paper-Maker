# Offline board content packs

This folder intentionally contains no fabricated or self-certified board question bank.

To create a pack, follow the schema and examples in the root `README.md` (schema versions 1–5). Each pack must cite the exact issuing authority, document title, session, source URL and page references. Keep the official model paper, Table of Specifications, syllabus/exclusion notice and marking scheme as separate source records when they are separate documents.

Before a pack is used in Official mode:

1. Verify the source document issuer and session from the original PDF/scan.
2. Transcribe the exact offered/attempted structure and all marks.
3. Independently cross-check chapter/SLO mapping and exclusions.
4. Resolve any contradiction between the model paper, ToS and marking scheme; do not silently choose one.
5. Confirm question wording, answers/marking guidance, copyright permissions and semantic duplicates.
6. Import the pack and approve source first, then pattern, then every question in the app's local review console.

Imported content always starts as `NEEDS_REVIEW`, regardless of status values in JSON.
